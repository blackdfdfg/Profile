v2.1.0 • PICTURE & PDF GUIDE

Pick a mode. Learn every control.

Log in with your Access Key and its X username. Select one of four modes, Save Settings, open X and press Profile Reload. These pictures use local sample data, not real balances or X actions. Store approval/version availability is separate.

Auto-Scroll

Read posts from the open X feed and generate relevant replies. This is not a profile list or a pasted-link queue.

  1. Choose Auto-Scroll in the popup and open the X feed you want to use.
  2. Press Profile Reload. Set the four Comment gap values and a Run time.
  3. Choose the Like and repost-related switches carefully. Commenting remains the main action.
  4. Press Start Auto-Scroll. Watch Live Status: comments, likes, next wait and running time.
  5. Press Stop to finish. If a real X comment/account restriction appears, stop and respect it.

You do not set a Follow cooldown in this mode. Optional Like failure switches Like OFF rather than pausing the whole comment run. Re-enable Like only when appropriate. A global or explicit comment/post restriction still stops work. No new artificial daily Comment quota was added.

Auto-Scroll is not the Link or Like queue. Their separate 48-hour Memory controls are not this feed’s controls. Avoid repeated posts and keep existing submission guards. Today used rolls over at 05:00 Bangladesh time when checked; All time used is the Access Key server total.

Link Engage

Open a queue of post links and generate a required reply for each eligible exact post. Like is optional.

  1. Paste post URLs in the input box. Named status links, i/status links and intent/like?tweet_id links are normalized.
  2. Press Find Links. Check the removed duplicate/own/Memory counts; use View Links to inspect the filtered queue.
  3. Set four Delay Between values, Pause After, and the optional Like Posts switch. Select comment billing in the extension popup.
  4. Press Start. Live activity replaces the link input while running. Watch counts, current item, waiting time and runtime.
  5. Press Stop before editing links. View Links → Find Links rebuilds the queue; Reset clears the current queue/progress/Failed archive, not saved Memory.

This mode does not add a daily Comment quota. Like-limit handling disables optional Like, not the required Comment run. Real comment/post/account restrictions and uncertain replies still stop safely. Stop cancels the scheduled Pause After; Start resumes pending work.

Link Memory lasts 48 hours and is independent from Like Memory and permanent Profile Memory. Completed and terminal failed attempts are remembered when ON. Find removes saved unexpired attempts. Memory Reset does not authorize retry of an uncertain submission; those guards remain.

Profile Engage

A three-stage profile follow-up workflow. List 1 finds and engages new profiles. List 2 checks for follow backs for seven days. List 3 holds expired profiles.

  1. Paste profile links or @usernames in 1 · New profiles. Extra text, query strings and trailing paths are cleaned by Find Links.
  2. Press Find Links, inspect View Links, then Run. Duplicate, own, permanent Memory and List 2/3 profiles are filtered.
  3. For a non-follower, check Follow/Following. Follow if needed, inspect the first 2–3 loaded posts, and reply to the newest eligible unliked original, regardless of age. Confirmed reply moves it to List 2.
  4. If the profile follows you, follow back when needed, then move it to Permanent Memory. Do not treat an unknown relationship as proof.
  5. Run 2 · Waiting for follow back to revisit the saved profiles. It continues from the next unfinished profile and loops after a full pass. Stop or Stop after controls when to finish.

Follow/Like/Unfollow rate warning immediately starts an 11-minute pause. Without a warning, Follow/Like can retry once only after verified OFF; two rollbacks pause. Stop remains visible during countdown. After the wait, the original pending profile is rechecked automatically in the original tab; warning again means another wait. Stop cancels the automatic wait and preserves the pending profile. Do not close X if you expect automatic continuation; a suspended/closed browser cannot run a timer.

Permanent Profile Memory has no automatic expiry; view, add or remove entries there. It is separate from Link/Like Memory. Private, sensitive or otherwise unavailable profiles are removed from the working list without a Failed archive/export. No warning is bypassed. Rate-limited profiles remain pending, not deleted. Three consecutive empty timelines still stop the run to avoid repeatedly acting on broken pages.

Like Engage

Open a queue of post links and like each exact post. No Generate, Comment, Repost or AI charge in this mode.

  1. Paste post URLs in the input box. Named status links, i/status links and intent/like?tweet_id links are normalized.
  2. Press Find Links. Check the removed duplicate/own/Memory counts; use View Links to inspect the filtered queue.
  3. Set four Delay Between values, Pause After, and Like limit break (minutes).
  4. Press Start. Live activity replaces the link input while running. Watch counts, current item, waiting time and runtime.
  5. Press Stop before editing links. View Links → Find Links rebuilds the queue; Reset clears the current queue/progress/Failed archive, not saved Memory.

Visible Like-limit warning pauses immediately; without it, only verified OFF permits one retry. Two rollbacks pause. The pending link resumes after the configured wait. Stop clears this local Like wait; a new Start with the warning still visible pauses again before a click. Stop cannot clear X’s limit.

This mode’s 48-hour Memory is separate from the other post queue and from permanent Profile Memory. A saved Link post does not remove a Like link or vice versa. Memory is account-scoped and browser-local; uninstalling/clearing data can erase it. Failed attempts are remembered when Memory is ON. Already-liked results are not failed exports.

Fresh installs: Auto-Scroll uses 4/5/6/7-second options and Skip reposted posts ON; existing saved settings stay unchanged. Profile delays cannot be below 5 seconds. Link/Like Memory lasts 48 hours and is separate between modes; Profile Memory has no expiry. The 2GB illustration is decorative, not reserved browser storage. Every Start/Run checks local licence expiry; a successful server check is reused for up to 72 hours, never beyond known expiry. If a due server check fails, a new run waits and retries no sooner than five minutes. Credit generation remains server-authenticated.

FAQ

Questions, answered

Is the extension free?

Installing is free from the Chrome Web Store. To use the agent you need a premium Access Key. Choose Fix Credits or use your own AI API key.

How do I pay with Binance?

Open the Binance app → Pay → Send → choose Binance ID → enter our ID shown at checkout → send the exact USDT amount. Then open the payment in your history and copy its Order ID.

Where do I find the Binance Order ID?

In Binance: Pay → History → tap the payment → copy the Order ID number. Paste it in step 2 of checkout.

Why do I enter my X username when buying?

Your Access Key is locked to that X username. In the extension you must log in with the key and the same username. Double-check it before paying.

The panel does not show on x.com.

Make sure you are logged in to the extension and one mode (Auto-Scroll or Link Engage) is on in Settings and saved. Then refresh x.com. On Android use a browser that supports Chrome extensions.

I lost my key. What now?

Log in here with the same Google/email account → My keys. You can copy the key, see its expiry and download the receipt any time.

Do I need my own AI API key?

No. Choose Fix Credits to use your key’s reply balance, or My API to use your own provider account. Each purchased key includes 300 welcome credits once.

What if my payment is not found?

Wait 1-2 minutes and try again. Make sure you sent the exact USDT amount within 30 minutes. Still stuck? Message us on Telegram with your Order ID.

Is my X account safe?

The agent uses random gaps, pauses and human-like actions. Still, use sensible settings (see Safety tips), automation always carries some risk.
