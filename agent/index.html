  1. Click Add to Chrome above. The Chrome Web Store opens.

PICTURE GUIDE

Every button, explained

Real screenshots of the extension. Use the Memory tab for the new gear settings, saved links and billing controls.

Login screen

Click the Fix icon in your browser toolbar. This window appears first.

  1. Access Key: paste the key you bought (looks like FIX-XXXXXX-…). Find it any time in My keys.
  2. X Username: the same username you entered when buying, without “@”. A different username will not work.
  3. LOGIN: checks your key. On success the Settings screen opens.
  4. Buy Access Key: opens this website to buy a key.
  5. Support: opens our Telegram for help.
One key = one X account. Your key is checked again quietly in the background, so keep it active.

Choose how replies are billed

The highlighted source and billing banner show exactly which account pays for replies.

  • Fix Credits: uses your key’s balance. One credit is reserved per generated reply; failed requests/posts can be refunded.
  • My API: uses your own provider account. It spends no Fix Credits and never falls back to credits when your API key is missing or invalid.
  • Credit wallet: see your balance, Buy Credits, and Reload balance. A friend can pay using your Access Key or purchased X username from their own website account.
  • Reply Style: up to 500 Unicode characters, with a live counter.
  • Modes: select Auto-Scroll or Link Engage, then Save Settings.

Auto-Scroll panel

Open x.com. The panel appears on the page (or tap the round Fix button at the bottom-right). Drag it anywhere and resize it from the corner.

  1. Profile Reload: reads which X account is logged in. It must match your key’s username. Do this once.
  2. Settings: show or hide the settings area.
  3. Keep open: keeps the panel open after a page reload.
  4. Comment gap: 4 wait times in seconds. A random one is used between comments, so it looks human.
  5. Run time (min): stops automatically after this many minutes. 0 = no limit.
  6. Like posts: also likes each post it replies to.
  7. Don’t repost: never reposts anything.
  8. Skip reposted posts: ignores posts that are reposts from others.
  9. Live Status: shows status, timer, comments, likes, the next wait and the current gap.
  10. Start Auto-Scroll: starts the agent.
  11. Stop: stops it right away.
Good start: gaps 60 · 90 · 120 · 150 sec, run time 30 min, Like on.

Link Engage, step by step

Turn on Link Engage in the extension popup and open x.com. Check Profile Reload before running a queue.

  • Paste and Find Links: extracts post links, removes repeated status IDs, your own username and recent attempts saved in Memory.
  • Comments + optional Like: Link Engage comments are required in v1.9. Turn Like on to also like posts; turning it off does not stop comments.
  • Start / Stop: Find Links only builds the queue. Start begins; Stop pauses the run.
  • Reset: clears the queue, progress and Failed Export archive, not saved Memory. Find Links preserves Failed Export; each failed link has an Open button. View Links returns the queue to the text box.
  • Gear beside Reload: opens Memory, current source and balance. Delay Between and Pause After stay on the main panel.
  • Delay: 0 and 1 second are accepted. One of four values is chosen each time. Set all four to 1 for a 1-second configured wait; loading, AI generation and posting still take additional time.
  • Home / Back: optional navigation happens after groups of 3, 4, 5, 6 or 9 processed links, not after every comment. This does not guarantee account safety.
Where is Memory? →

Memory remembers attempts for 24 hours

Memory is local history, not your current queue. Completed and failed attempts are recorded separately for each X username.

  1. Gear: next to Reload. Open it to find all Memory settings. Back returns to the queue.
  2. Saved count: the number of unexpired link IDs stored for this X account.
  3. Memory on/off: on filters and saves attempts; off stops both. Turning off does not erase older records.
  4. Reset memory: clears this account’s saved attempts after confirmation. Ordinary queue Reset does not.
  5. Reply source: shows Fix Credits or My API, with its billing rule.
  6. Credit balance: shows available credits and Reload balance. My API does not use this balance.
100 → 95 → 85: 100 pasted links minus 2 duplicates and 3 of your own links leaves 95. After 10 completed or failed attempts, Stop → View Links → Find Links leaves 85 when Memory is on.

Find Links removes expired records after 24 hours. Duplicate detection uses the post/status ID, even when the URL’s username or query differs. To retry a failed attempt sooner, stop the queue and reset Memory deliberately. If submission was unconfirmed, inspect the post manually: its separate 24-hour automatic-retry guard remains, even after Memory Reset.

Use real gaps

Keep comment gaps at 60 seconds or more. Faster is riskier.

Short sessions

Run 20-40 minutes, then take a break. Use Run time to stop automatically.

Pause in Link Engage

Use Pause After (e.g. 10 links → 5 min) for long lists.

Pick a good style

Friendly and helpful replies get the best results.

Keep keys private

Never post keys publicly or share your AI API key. For gifts, use your purchased X username instead of sharing the key. The key stays bound to your X username.

FAQ

Questions, answered

Is the extension free?

Installing is free from the Chrome Web Store. To use the agent you need a premium Access Key. Choose Fix Credits or use your own AI API key.

How do I pay with Binance?

Open the Binance app → Pay → Send → choose Binance ID → enter our ID shown at checkout → send the exact USDT amount. Then open the payment in your history and copy its Order ID.

Where do I find the Binance Order ID?

In Binance: Pay → History → tap the payment → copy the Order ID number. Paste it in step 2 of checkout.

Why do I enter my X username when buying?

Your Access Key is locked to that X username. In the extension you must log in with the key and the same username. Double-check it before paying.

The panel does not show on x.com.

Make sure you are logged in to the extension and one mode (Auto-Scroll or Link Engage) is on in Settings and saved. Then refresh x.com. On Android use a browser that supports Chrome extensions.

I lost my key. What now?

Log in here with the same Google/email account → My keys. You can copy the key, see its expiry and download the receipt any time.

Do I need my own AI API key?

No. Choose Fix Credits to use your key’s reply balance, or My API to use your own provider account. Each purchased key includes 300 welcome credits once.

What if my payment is not found?

Wait 1-2 minutes and try again. Make sure you sent the exact USDT amount within 30 minutes. Still stuck? Message us on Telegram with your Order ID.

Is my X account safe?

The agent uses random gaps, pauses and human-like actions. Still, use sensible settings (see Safety tips), automation always carries some risk.
