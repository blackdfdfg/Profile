STEP 1 · INSTALL

Install the extension

Free to install. You only need an Access Key to unlock the agent.

Chrome Web StoreAdd to Chrome

On PC (Google Chrome)

  1. Click Add to Chrome above. The Chrome Web Store opens.
  2. Press Add to Chrome → Add extension.
  3. Click the puzzle icon at the top-right of Chrome and press the pin next to Fix.
  4. Click the Fix icon to open the login window.

On Android (Kiwi Browser)

  1. Install Kiwi Browser from the Play Store.
  2. In Kiwi, open the Add to Chrome link above (Chrome Web Store).
  3. Tap Add to Chrome → OK.
  4. Tap ⋮ menu → scroll down → Fix to open the extension.

After installing, open x.com once and refresh the page so the agent can load.

PICTURE GUIDE

Every button, explained

Real screenshots of the extension. Each number on the picture matches the list.

Login screen

Click the Fix icon in your browser toolbar. This window appears first.

  1. Access Key — paste the key you bought (looks like FIX-XXXXXX-…). Find it any time in My keys.
  2. X Username — the same username you entered when buying, without “@”. A different username will not work.
  3. LOGIN — checks your key. On success the Settings screen opens.
  4. Buy Access Key — opens this website to buy a key.
  5. Support — opens our Telegram for help.
One key = one X account. Your key is checked again quietly in the background, so keep it active.

Settings

Choose your AI, add your API key and pick which tool to use.

  1. AI Provider — OpenAI, Gemini or DeepSeek. Use the one you have an API key for.
  2. Model — the AI model. The one marked ★ Suggested is a good, low-cost choice.
  3. API key — paste your provider’s API key. The eye shows/hides it.
  4. + Add key — add up to 3 keys. They take turns for each comment, and if one fails the next one is used.
  5. Reply Style — the tone of your replies (friendly, professional, funny…).
  6. Control Panel (Auto-Scroll) — turn on to scroll your feed and reply automatically.
  7. Link Engage — turn on to work through a list of post links. Only one mode can be on at a time.
  8. Save Settings — always press this after a change.
  9. Logout — signs out of the extension on this browser.
Get an API key: OpenAI · Gemini · DeepSeek

Auto-Scroll panel

Open x.com. The panel appears on the page (or tap the round Fix button at the bottom-right). Drag it anywhere and resize it from the corner.

  1. Profile Reload — reads which X account is logged in. It must match your key’s username. Do this once.
  2. Settings — show or hide the settings area.
  3. Keep open — keeps the panel open after a page reload.
  4. Comment gap — 4 wait times in seconds. A random one is used between comments, so it looks human.
  5. Run time (min) — stops automatically after this many minutes. 0 = no limit.
  6. Like posts — also likes each post it replies to.
  7. Don’t repost — never reposts anything.
  8. Skip reposted posts — ignores posts that are reposts from others.
  9. Live Status — shows status, timer, comments, likes, the next wait and the current gap.
  10. Start Auto-Scroll — starts the agent.
  11. Stop — stops it right away.
Good start: gaps 60 · 90 · 120 · 150 sec, run time 30 min, Like on.

Link Engage panel

Turn on Link Engage in Settings, then open x.com. Paste post links and the agent visits each one, likes and replies.

  1. Profile Reload — detect your X account (once).
  2. Settings — show / hide options.
  3. Keep open — stay open after reload.
  4. Links box — paste any text with X post links. Messy text is fine.
  5. Find Links — pulls out clean post links and removes duplicates.
  6. Reset — clears the list and progress.
  7. View Links — see the found list.
  8. Total / Progress — how many links and how many are done.
  9. Export — download the list with results.
  10. Delay Between — 4 wait times (sec); a random one is used between links.
  11. Pause After — rest for M minutes after every N links.
  12. Like Posts — also like each post.
  13. Counters — Success, Failed, Status and the Current link.
  14. Start — begin working through the list.
  15. Stop — stop any time; progress is saved.
Each post is opened only once — already-done links are skipped.

Use real gaps

Keep comment gaps at 60 seconds or more. Faster is riskier.

Short sessions

Run 20–40 minutes, then take a break. Use Run time to stop automatically.

Pause in Link Engage

Use Pause After (e.g. 10 links → 5 min) for long lists.

Pick a good style

Friendly and helpful replies get the best results.

Keep keys private

Never share your Access Key or AI API key. Your key works only with your X username.

Something stuck?

Refresh x.com, press Profile Reload, then Start again. Still stuck? Telegram.

FAQ

Questions, answered

Is the extension free?

Installing is free from the Chrome Web Store. To use the agent you need a premium Access Key from this site, plus your own AI API key.

How do I pay with Binance?

Open the Binance app → Pay → Send → choose Binance ID → enter our ID shown at checkout → send the exact USDT amount. Then open the payment in your history and copy its Order ID.

Where do I find the Binance Order ID?

In Binance: Pay → History → tap the payment → copy the Order ID number. Paste it in step 2 of checkout.

Why do I enter my X username when buying?

Your Access Key is locked to that X username. In the extension you must log in with the key and the same username. Double-check it before paying.

The panel does not show on x.com.

Make sure you are logged in to the extension and one mode (Auto-Scroll or Link Engage) is on in Settings and saved. Then refresh x.com. On Android use Kiwi Browser.

I lost my key. What now?

Log in here with the same Google/email account → My keys. You can copy the key, see its expiry and download the receipt any time.

Do I need my own AI API key?

Yes. Add your OpenAI, Gemini or DeepSeek key inside the extension. You only pay your provider for what you use.

What if my payment is not found?

Wait 1–2 minutes and try again. Make sure you sent the exact USDT amount within 30 minutes. Still stuck? Message us on Telegram with your Order ID.

Is my X account safe?

The agent uses random gaps, pauses and human-like actions. Still, use sensible settings (see Safety tips) — automation always carries some risk.
