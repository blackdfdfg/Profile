STEP 1 · INSTALL

Install the extension

Free to install. You only need an Access Key to unlock the agent.

On PC (Google Chrome)

  1. Click Add to Chrome above. The Chrome Web Store opens.
  2. Press Add to Chrome → Add extension.
  3. Click the puzzle icon at the top-right of Chrome and press the pin next to Fix.
  4. Click the Fix icon to open the login window.

On Phone (Android)

  1. Use a phone browser that supports Chrome extensions.
  2. Open the Add to Chrome link above (Chrome Web Store).
  3. Tap Add to Chrome → OK.
  4. Tap the browser ⋮ menu → Extensions → Fix to open it.

After installing, open x.com once and refresh the page so the agent can load.

FIX 3.5.0 · QUICK GUIDE

Four modes. Clear controls.

This guide describes the prepared v3.5.0 extension; Store availability depends on approval. Choose one mode in the extension settings, save, and open X.

Auto-Scroll

Work through the open feed using your configured reply style, timing and optional actions. Stop if X reports a restriction.

Link Farming

Paste post links and select Only Like or Like + Comment in the panel. Each mode keeps its own memory and timing. Review the queue before starting.

Profile Engage

Scan the profiles first; run the eligible second list. Profiles leave the queue after seven days without being unfollowed. Mutuals can be kept in Profile Memory.

Followers Management

Scan followers or following, review filters, set limits and timing, then follow or unfollow from the bottom of the list. Locked profiles are protected.

Open the guide inside each extension panel for detailed instructions and supported languages. X limits can change; timing controls cannot guarantee account safety. A successful licence check can be reused for up to 72 hours, subject to the key’s known expiry.

FAQ

Questions, answered

Is the extension free?

Installing is free from the Chrome Web Store. Use a paid Access Key, or contact support to ask about free access after an ownership check. Choose Fix Credits or use your own AI API key.

How do I pay with Binance?

Open the Binance app → Pay → Send → choose Binance ID → enter our ID shown at checkout → send the exact USDT amount. Then open the payment in your history and copy its Order ID.

Where do I find the Binance Order ID?

In Binance: Pay → History → tap the payment → copy the Order ID number. Paste it in step 2 of checkout.

Why do I enter my X username when buying?

Your Access Key is locked to that X username. In the extension you must log in with the key and the same username. Double-check it before paying.

The panel does not show on x.com.

Make sure you are logged in to the extension and one mode (such as Auto-Scroll or Link Farming) is on in Settings and saved. Then refresh x.com. On Android use a browser that supports Chrome extensions.

I lost my key. What now?

Log in here with the same Google/email account → My keys. You can copy the key, see its expiry and download the receipt any time.

Do I need my own AI API key?

No. Choose Fix Credits to use your key’s reply balance, or My API to use your own provider account. New paid and approved free keys include 500 welcome credits once.

What if my payment is not found?

Wait 1-2 minutes and try again. Make sure you sent the exact USDT amount within 30 minutes. Still stuck? Message us on Telegram with your Order ID.

Is my X account safe?

Timing and limits offer controls, not a guarantee of safety. X may restrict automated actions; stop when a restriction appears.
