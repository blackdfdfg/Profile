PICTURE GUIDE

Every button, explained

Updated for v2.0: the extension popup, running queue and Memory settings. The Settings button is now beside Like Posts, not beside Reload.

These pictures show the v2.0 interface with sample values. Publishing this guide does not update your installed extension. Check the Chrome Web Store version; update and reload open X tabs after installation.

Log in with your purchased key

  1. Access Key: paste your purchased key. Find it in My keys; never share it publicly.
  2. X username: use the username linked to that key and sign in to the same account on x.com.
  3. Login: opens the settings popup after validation. Three definite failed key/username checks trigger a five-minute local cooldown; network/server errors do not count.
  4. Profile Reload: on the X-page panel, follow the cursor hint and press Reload to detect your profile before starting.
Website login and extension Access Key login are different. Updating this website does not install v2.0 for you.

Your balance. Your reply source.

  • Balance + Top up: stay at the top, including in API mode. Reload fetches the current balance.
  • Use credit balance: shows Today used, All time used and the one-credit-per-reply rule. A credit is reserved for generation; eligible failures are refunded.
  • Today used: confirmed credit replies on this browser for this Access Key. The day starts at 05:00 Bangladesh time (Asia/Dhaka). Both Start buttons check rollover; reads and subsequent settlement also check. Idle UI does not run a reset alarm. Other devices are not combined.
  • All time used: server-side credit-wallet usage for your Access Key. The same key reloads its current total after logout/login; the daily reset does not reset it. It is not a count of My API replies.
  • Use API key: choose your provider and model. MiMo and Qwen are included. The catalogue shows starter options before a key; a valid provider key can load available text models. Availability and pricing depend on your provider.
  • No credit fallback: missing or invalid API keys never silently spend Fix Credits. Stop the queue before changing source.
  • Reply Style + Modes: up to 500 Unicode characters; select compact Auto-Scroll or Link Engage, then Save Settings.
Today used is browser-local. Uninstalling or clearing extension data removes it and local Memory. The server credit wallet is separate. On the first upgrade, an available old daily count can be carried once; subsequent days use the 05:00 boundary.

Auto-Scroll on x.com

  1. Enable: choose Auto-Scroll in the popup and Save Settings. Open x.com and tap the floating Fix launcher if the panel is hidden.
  2. Profile Reload: detect the account and ensure it matches your Access Key.
  3. Settings: review timing and action controls. Choose a comment gap and run time appropriate for your account; 0 run time means no automatic time limit.
  4. Start / Stop: Start checks licence and the local Today boundary, then starts the run. Stop pauses processing.
  5. Status: follow the timer and counters. Stop before changing account or reply source.
Timing and visual scrolling do not bypass X rules or rate limits. Use only accounts you are authorised to operate.

Build the queue. Then start.

  1. Reload first: follow the cursor hint on first use and detect the same X account as your key.
  2. Paste → Find Links: builds the queue; it does not start engagement. A five-second notice explains how many Memory, duplicate and own links were removed. Duplicates are compared by post ID.
  3. Like Posts + Settings: share one row. Comments remain required; Like is optional. There is only one Settings button, beside Like Posts.
  4. Start: hides the link editor, Find Links, Reset and View Links while running. Live activity appears in their place; progress, delay, pause and Stop remain available.
  5. Stop: restores the queue editor. View Links puts the queue back in the text box. Reset clears queue/progress/Failed Export, not Memory.
  6. Reply flow: the agent opens a post, may preview-scroll, opens the composer, uses Generate, then submits Reply and checks confirmation. Manual Generate only prepares a draft.
  7. Retry: a recoverable pre-submit failure can be reopened once. Already-commented or reply-restricted posts, account changes and provider/auth/rate/credit errors are not automatically reopened. An unconfirmed submission is not auto-retried: inspect it manually to avoid a duplicate.
  8. Failed Export: shows failed links, reasons and an Open action. Find Links keeps that archive; ordinary Reset clears it.

Delay Between chooses from your four values; 0 and 1 second are accepted but loading, AI and posting add time. Pause After sets a timed break. Faster is not safer.

Open Memory instructions →

Memory is history, not your queue

  1. Open Settings: beside Like Posts. There is no settings gear beside Reload in v2.0. Back returns to the main panel.
  2. 24-hour Memory: completed and failed attempts are saved locally, separately per X username. The count excludes expired records.
  3. Memory on/off: on saves and filters attempts; off stops both without immediately deleting older history. Duplicate and own-post filtering still work.
  4. Remove selected links: stop the queue, paste post links and Confirm removal. Only matching records for this account are removed; other accounts are unchanged.
  5. Remove all memory: read the warning, then press Confirm removal. Previously saved posts may be processed again. Cancel leaves them unchanged.
  6. Unconfirmed submissions: their separate 24-hour retry guards survive either Memory removal. Inspect those posts manually.
  7. Reply source / balance: shows Fix Credits or My API, billing guidance, Top up and Reload balance. Change source in the extension popup, not here.
  8. How it works: opens the packaged English guide / PDF.
Queue Reset never clears Memory. Clearing browser/extension data can remove local history. The 2GB chip is decorative artwork, not allocated storage or an account-safety guarantee.

Use real gaps

Keep comment gaps at 60 seconds or more. Faster is riskier.

Short sessions

Run 20-40 minutes, then take a break. Use Run time to stop automatically.

Pause in Link Engage

Use Pause After (e.g. 10 links → 5 min) for long lists.

Pick a good style

Friendly and helpful replies get the best results.

Keep keys private

Never post keys publicly or share your AI API key. For gifts, use your purchased X username instead of sharing the key. The key stays bound to your X username.

FAQ

Questions, answered

Is the extension free?

Installing is free from the Chrome Web Store. To use the agent you need a premium Access Key. Choose Fix Credits or use your own AI API key.

How do I pay with Binance?

Open the Binance app → Pay → Send → choose Binance ID → enter our ID shown at checkout → send the exact USDT amount. Then open the payment in your history and copy its Order ID.

Where do I find the Binance Order ID?

In Binance: Pay → History → tap the payment → copy the Order ID number. Paste it in step 2 of checkout.

Why do I enter my X username when buying?

Your Access Key is locked to that X username. In the extension you must log in with the key and the same username. Double-check it before paying.

The panel does not show on x.com.

Make sure you are logged in to the extension and one mode (Auto-Scroll or Link Engage) is on in Settings and saved. Then refresh x.com. On Android use a browser that supports Chrome extensions.

I lost my key. What now?

Log in here with the same Google/email account → My keys. You can copy the key, see its expiry and download the receipt any time.

Do I need my own AI API key?

No. Choose Fix Credits to use your key’s reply balance, or My API to use your own provider account. Each purchased key includes 300 welcome credits once.

What if my payment is not found?

Wait 1-2 minutes and try again. Make sure you sent the exact USDT amount within 30 minutes. Still stuck? Message us on Telegram with your Order ID.

Is my X account safe?

The agent uses random gaps, pauses and human-like actions. Still, use sensible settings (see Safety tips), automation always carries some risk.
